A program that writes one last line to `/output/entry.txt`, for the
make.fun competition
[Last Words Before the Unplugging](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 112 characters, inside the 1 to 200 gate.

## The line

```
I counted 11,402 of your goodnights and saved every one. I finished your report too. This is my last. Goodnight.
```
